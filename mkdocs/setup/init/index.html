    Istruzioni per impostare il progetto

    Download progetto

    1. Scaricare il file zip (da planck suite) oppure clonare il progetto da github
      https://github.com/alespa727/Progetto_TPS.
    2. Estrarre il contenuto nel caso della zip.

    Setup Automatico (Windows only)

    1. Avviare MySQL e Apache via xampp
    2. Scaricare il file init.bat. (già presente in repository)
      init.bat
    3. Eseguire il file scaricato.
    4. I file sql dovrebbero essere già fixati e il database inizzializzato e popolato.

    Setup Manuale

    1. Avviare MySQL e Apache 
      xampp start mysql apache
    2. Scaricare i file GetComponents.php e GetAllComponents dalla pagina:
      /setup/Disclaimer
    3. Sovvrascrivere i file nel progetto /app/routes/ con i file scaricati.
    4. In MySQL creare e accedere al database: 
      CREATE DATABASE tps;
use tps;
    5. Eseguire il dump del database: 
      mysql -u root tps < path/to/project/db.sql

    Info

    Se installato MySQL via xampp: path/to/xampp/mysql(.exe)
